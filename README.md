# Мобильный робот: навигация по линии

Скетч Arduino для подготовки к практической олимпиаде по робототехнике. Робот с дифференциальным приводом следует по чёрной линии, определяет перекрёстки, строит маршрут по известному полю и считывает наличие объектов в зонах размещения.

## Что реализовано

- Управление двумя моторами по энкодерам, движение на заданное расстояние и поворот на заданный угол.
- Следование по линии с пропорциональной коррекцией по двум аналоговым датчикам.
- Обнаружение обычных и односторонних перекрёстков.
- Ориентирование на графе из 12 точек: `pole` хранит переходы в формате `{откуда, куда, направление}`.
- Построение маршрута с учётом направления корпуса. Стоимость перехода равна `1`, поворот на 90° добавляет `2`, разворот — `4`. Глобальные `now` и `poz` хранят текущую точку и абсолютное направление (`1` вверх, `2` вправо, `3` вниз, `4` влево).
- Считывание объектов датчиками расстояния, управление захватом и светодиодной линейкой.

## Подключение

| Компонент | Контакты |
| --- | --- |
| Моторы | 4, 5, 6, 7 |
| Энкодеры | 2, 3, 8, 9 |
| Датчики линии | A0, A1 |
| Левый датчик расстояния | 10, 13 |
| Правый датчик расстояния | A3 |
| Сервоприводы | 11, 12 |
| NeoPixel | A5, 8 светодиодов |

## Сборка

Откройте `arduino-robotics-olympiad.ino` в Arduino IDE. Нужны библиотеки **Servo** и **Adafruit NeoPixel**. Перед запуском проверьте пороги `whiteRigth`, `whiteLeft`, `grey`, коэффициент `MM_TO_TICKS`, базу колёс `WHEEL_BASE_MM` и начальные значения `now`, `poz`.

Скетч успешно компилируется для **Arduino Uno** с Arduino AVR Boards 1.8.8, Servo 1.3.0 и Adafruit NeoPixel 1.15.5. Это проверка сборки, а не подтверждение движения на реальном поле.

## Текущее состояние

`loop()` сейчас выполняет проверочный сценарий: переход `0 → 6`, сканирование первой зоны и попытку перехода `6 → 2`, после чего завершает выполнение. Дальнейшая последовательность зон ещё не включена в основной цикл. Возврат `6 → 2` и соответствие подсчёта перекрёстков физическому положению после сканирования требуют проверки на полигоне. Функции сканирования перемещают робота, но не обновляют `now`; перед объединением полного сценария это состояние нужно синхронизировать.

Регламент категории задаёт общие ограничения для робота и командной работы, а конкретное задание и схема поля выдаются отдельно. Этот репозиторий содержит подготовительный скетч для показанного поля.
